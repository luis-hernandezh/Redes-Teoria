Model Context Protocol (MCP) para Sistemas Dinámicos

Los Modelos de Lenguaje (LLMs) carecen de rigor numérico para resolver sistemas dinámicos complejos. Nuestro servidor MCP actúa como un orquestador que intercepta las peticiones y las delega a motores de cálculo exactos en Python.

Flujo de Ejecución del Servidor

1. Entrada de Usuario (LLM)
↓
2. server.py (Validación MCP)
↓
3. matematica.py (Cálculo Numérico)
↓
4. visualizacion.py (Renderizado)
↓
5. Respuesta JSON + Gráficos Base64
